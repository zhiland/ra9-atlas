# Source license audit

Snapshot: 2026-10-18; Stormy Night source scope added 2026-10-20. Scope: the public sources registered in [SOURCES.md](../SOURCES.md), checked against each site's own license, terms, or repository files on 2026-10-18; the additional Stormy Night pages reuse the same site terms recorded for those publishers. Only public pages were read; no vault, credential, or log material was inspected.

This audit records what those pages state; it is not legal advice, is not a binding legal opinion, and does not clear any material for reuse. Reading and linking are distinct from reproducing authored text, transcripts, images, or datasets. Independently checking facts can reduce reliance on a source's wording, but does not by itself resolve rights in copied expression or selection and arrangement. Public visibility (including a public GitHub repository with no license file) is not a reuse license. Game dialogue, flowchart imagery, and screenshots involve Quantic Dream/Sony material regardless of what a fan site's own terms say.

## Project interpretation and current PoC4 status

The findings below are source-specific evidence and recommendations, not
automatic legal conclusions or a blanket instruction to remove existing
project material. PoC4 adds no screenshots, game art, or copied guide corpus.
Its A New Home segment is a ten-node, nine-link transcription of a Steam
guide screenshot; event labels and ordering therefore retain that source
provenance even though the prototype uses short labels and original
explanatory summaries. The audit found no reuse license for that screenshot.
PoC4 remains local pending targeted review. The existing published PoC3 files
are unchanged; the audit recommendation about The Hostage transcription is
recorded for review and does not itself alter or withdraw that material.

Rights layers used below: **code**; **data/text** (structured data, authored prose, transcripts); **assets** (screenshots, images, game art/UI); **design references** (third-party website styling shown as inspiration). “No broad permission identified” means no reuse license was found on the checked public pages; it does not prove none exists.

## Cross-cutting issues

- **Game IP layer.** Every flowchart image, screenshot, and dialogue transcript traces back to *Detroit: Become Human* (Quantic Dream/Sony). A permissive license on a fan project's code or notes does not extend to game-derived material; treat images and transcripts as off-limits unless permission exists.
- **Site terms vs. content.** Several sites (PowerPyx, Neoseeker, Gamer Guides) state clear prohibitions; others (Game of Guides, Detroit Become Text, fschutt) simply state nothing. No reuse license was identified for those sources; the audit does not infer a particular legal default from silence.
- **Fandom boundary.** The CC-BY-SA footer covers community-edited wiki prose, not game images/files, and not “otherwise noted” content. Check per-page attribution before reusing any wiki text.
- **GitHub default.** No license file was found in the public fschutt and Detroit Become Text repositories; public visibility alone does not establish permission to reuse their code or data. MIT (Detroit AI Player runner) and Apache-2.0 (Impeccable) apply only to files within their stated scope; CC BY-NC 4.0 data is non-commercial.
- **Derived material.** The *The Hostage* mockup transcription derived from the Steam guide image is derived from game-derived imagery; keep it as internal evidence notes and prefer independently worded, separately verified facts in any published output.

## Practical recommendations

1. Avoid copied screenshots, game art, flowchart images, and transcript prose without a license or written permission; do not add them to the published prototype.
2. Write concise labels and summaries independently; cite the source for the fact, not its wording.
3. Preserve existing attributions (guide authors, Steam credits, repo authors) even where not strictly required.
4. Before reusing anything, re-check the exact page license/terms; terms change and can differ per page.
5. Where reuse might ever be desired, request written permission (Neoseeker, PowerPyx, Gamer Guides) rather than assuming.
6. For code reuse: MIT (Detroit AI Player runner) and Apache-2.0 (Impeccable) carry license and notice obligations; CC BY-NC 4.0 data is non-commercial only.
7. Treat all source claims (completeness, thresholds, outcomes) as unverified until checked in-game or against independent evidence; rights and accuracy are separate questions.
