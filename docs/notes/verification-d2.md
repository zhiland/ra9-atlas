# D2 — A New Home → Battle for Detroit (Kara)

Check date: October 17, 2026; D2.1 key-threshold attribution corrected after full-text review on October 20, 2026. Game version/platform are unknown; no gameplay run or original flowchart was checked.

**Verdict: HOLD** for use as a verified game example or confirmed complete data set. **GO** only as a labeled hypothetical mockup and scenario for further checking. Secondary guides support the main chain, but this is not in-game verification. Do not replace the full set of conditions with one JSON variable.

## Atomic claims

- **D2.1 — key to the box:** PowerPyx lists friendly conversation choices with Alice followed by obtaining the key but does not state a relationship threshold. The reviewed GameFAQs/Mogg text says Alice trusts Kara enough to give the key but does not name Neutral or another level; it also says the box needs the key. The exact relationship level is therefore unknown. Both guide pages were re-read in full text on 2026-10-20. [PowerPyx, *A New Home*, “Talk with Alice” / “Open Alice’s Box”](https://www.powerpyx.com/detroit-become-human-a-new-home-walkthrough-100/); [GameFAQs, *A New Home*](https://gamefaqs.gamespot.com/ps4/182637-detroit-become-human/faqs/76123/a-new-home).

Status: secondary evidence from transcript text, not a gameplay capture. Status: claimed by Fandom and Neoseeker; the guides do not count as independent in-game confirmation. ## Discrepancy and evidence limits

The exact flag is unresolved: models and some discussions describe the condition as “see the photo/inspect the box,” while Fandom/Neoseeker say to open it, and the found JSON reduces the effect to `ch04_opened_box`. It is unknown whether the game requires opening the box, merely seeing a family photo, or checks a related dialogue node. A primary capture of the in-game flowchart/dialogue with controlled states is needed; none is available here. A useful but separate fallback — injured police officer in *The Hostage* → *Public Enemy* — was not checked in this review and does not replace D2.

## Replay caveat

Replaying a chapter with saving changes the current playthrough branch and may lose later progress; without saving, an alternative can be viewed, but its carry-over into a later chapter cannot be checked. This is described in a review of the flowchart mechanic [Meristation, “Flowchart”](https://as.com/meristation/2018/05/24/analisis/1527163200_175923.html); it has not been confirmed on a specific game version. D2 needs a controlled full playthrough: *A New Home* (box open/closed) → *Stormy Night* (Todd alive/killed) → *Battle for Detroit* (persuasion options), recording the initial flowchart and outcome. Safe ways to isolate branches without losing later progress were not checked.
