# Implementation roadmap

The goal remains a complete, source-audited guide to all Detroit: Become Human chapter charts and their cross-chapter consequences. The current PoC is a useful renderer and data-method sample, not a production guide: **102 nodes, 93 modeled edge claims, and five chapter regions**. The Hostage source chart shows 36 connectors; the option-specific model has 37 claims because it separates one connector into distinct Friendly and Cold choice candidates. *The Hostage* is accounted against its visible chart; the other four regions are partial (A New Home, Stormy Night, Battle for Detroit — Kara, and one *Public Enemy* meeting node). None of its game transitions has been verified in-game.

This roadmap replaces the earlier sequence of isolated PoC expansions. The Stage 1 pilot now accounts for one chapter's visible topology and one bounded cross-chapter carry. The next content milestone is review of that pilot and a production-ready method before scaling through planned chapter batches, not accumulating disconnected sample events. An explicitly incomplete public preview remains allowed when its coverage gaps are visible; full-game coverage remains the end goal.

## Execution handoff

After the chapter-preparation package reaches a clean, tested commit, use
[the Sol handoff](handoff-sol.md) for the next bounded work package. Start with
GPT-6.1 Sol at the client's default reasoning effort. Raise effort for a hard
local task; bring Astra back for a cross-stage decision with unresolved source,
architecture, rights or product tradeoffs. Keep independent source review and
the stage gates regardless of model. Recheck branch and PR state before work;
the handoff records a point in time and authorizes no automatic merge or
publication.

## Working rules from the PoC

- Do not treat screenshot-transcribed official chart structure and supplementary guide events as interchangeable. Label each source type and keep source-derived rights separate from the MIT license for original code and documentation.
- A reported sequence is not automatically an eligibility condition. Conditions are edge-local unless evidence explicitly gates multiple edges. Keep `unknown` distinct from source conflict and hypothesis; do not turn an omitted guide step into optionality or a required step.
- Stable IDs and permalinks are part of the data contract. Plan compatibility before changing the current `?edge=N` canonical form.
- Maintain the single map world across zoom levels. The 1,000-node SVG benchmark is synthetic performance evidence only; it does not prove real-content readability or require a renderer rewrite.
- Run data, source-review, desktop, and mobile checks throughout each batch. Keep source accuracy, graph coverage, interaction behavior, and accessibility as separate claims.
