# ra9-atlas

An unofficial, evidence-labeled map prototype for choices and consequences in **Detroit: Become Human**.

**Status:** PoC4 is implemented in `main`, with neutral-gray default styling and orthogonal arrow connectors. Validators, 25 unit checks, and 42 Chromium checks pass. This is a guide-based prototype, not a complete or in-game-verified map.
