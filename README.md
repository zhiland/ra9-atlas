# ra9-atlas

An unofficial interactive guide to choices and consequences in **Detroit: Become Human**.

**Status: research and specification. No application is available yet.**

## Goal

Select an action. See its prerequisites and follow its later consequences.
Explore the full game without switching between flowchart screenshots.

The planned interface is English-only. It will show a spoiler warning before revealing the full map.
Fog of war is deferred.

## Findings so far

- No complete replacement was confirmed among the checked candidates. This is not an exhaustive absence claim.
- Existing structured data can simplify game mechanics. It must not be accepted as an exact game map without verification.
- Three examples were compared against guides. They are suitable for a labeled mockup, but are not game-verified.

See [Gate 01](notes/decision-gate-01.md) and [Gate 02](notes/decision-gate-02.md).
Research notes contain **spoilers**.
