# ra9-atlas

An unofficial, evidence-labeled map prototype for choices and consequences in **Detroit: Become Human**.

**Status:** PoC4 is a partial, guide-backed prototype with neutral-gray default styling and orthogonal arrow connectors. The stable-zoom renderer keeps the same real nodes, labels, chapter regions, and connectors at every camera scale; zoom changes only the camera transform. Validators, 70 contract-fixture checks, 43 unit checks, 4 map checks, 10 stable-zoom checks, 11 layout checks, and 55 Chromium checks pass. This is not a complete or in-game-verified map.
