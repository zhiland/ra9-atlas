# ra9-atlas

An unofficial, evidence-labeled map prototype for choices and consequences in **Detroit: Become Human**.

**Status:** PoC4 is implemented in `main`, with neutral-gray default styling, orthogonal arrow connectors and a chapter-level whole-story overview that reveals event boxes and labels as you zoom. Validators, 45 contract-fixture checks, 42 unit checks, 13 map-first checks, and 51 Chromium checks pass. This is a guide-based prototype, not a complete or in-game-verified map.
